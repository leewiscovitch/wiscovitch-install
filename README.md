# wiscovitch-install

Source for <https://install.wiscovitch.org>, a page of copy/paste steps for setting up a fresh OS.

- Edit `index.md` to add or change steps. Use fenced code blocks; each one gets a **Copy** button.
- GitHub Pages builds and publishes the site on every push to `main`.
- This repo is public. Never put passwords, keys or tokens in it; use placeholders like `<WIFI_PASSWORD>`.
